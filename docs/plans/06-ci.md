# Plan 06 — CI for the headless suites

**Theme:** maintainability · **Effort:** S · **Priority:** medium

## Why

There is currently no CI. A regression in the parsing/engine/schema logic would
only be caught by hand. Crucially, that logic is now deliberately **vscode-free**
(`src/enrichedSchemaCore.ts`, `src/datasetEngineCore.ts`, `src/indexFileModel.ts`,
`src/*Utils.ts`), so its tests run under plain Node/mocha without the Electron host
— cheap to gate in CI. The Python merge scripts have stdlib-only `unittest` suites
too.

## Goal

A GitHub Actions workflow that, on every PR and push, runs type-check, lint, the
vscode-free TS tests, and the Python tests — and packages the vsix to catch
packaging breakage.

## Design

Add `.github/workflows/ci.yml`:

1. **Job: build & test (Node)**
   - `actions/setup-node` (Node 22, matching `@types/node`).
   - `npm ci`.
   - `npm run check-types` and `npm run lint`.
   - `npm run compile-tests` (tsc → `out/`).
   - Run the vscode-free suites directly with mocha, e.g.
     `npx mocha out/test/enrichedSchemaCore.test.js out/test/datasetEngineCore.test.js out/test/indexFileModel.test.js out/test/fileFormatUtils.test.js out/test/pathUtils.test.js out/test/outputDataFrameUtils.test.js`.
     (The Electron `vscode-test` run needs a display and downloads VS Code — skip it
     in CI, or add a separate `xvfb`-gated job later.)
2. **Job: python tests**
   - `actions/setup-python` (3.11+).
   - `python -m unittest scripts.test_merge_overlays scripts.test_merge_output_families`.
3. **Job: package**
   - `npm ci && npm run package && npx vsce package --allow-star-activation`
     (drop the flag once Plan 05 lands). Upload the vsix as a build artifact.

## Optional niceties

- A scheduled job that regenerates the enriched/output schemas from a checked-out
  `swatplus-doc-builder` and fails if the committed JSON is stale (keeps docs fresh
  when overlays change).
- Cache `~/.npm` for faster installs.

## Acceptance

- PRs show passing/failing checks for type-check, lint, TS tests, Python tests, and
  packaging.
- A deliberately broken test fails the workflow.
- The vsix artifact is downloadable from the workflow run.
